## 版本目录

- `versions/v1.0/`：初代正式版，模组版本 1.0。
- `versions/v2.0.9/`：当前正式版，模组版本 2.0.9。

各版本均保存为独立、完整的模组目录，可以单独下载和安装。正式游玩建议使用最新版本。

## 手动安装

1. 下载需要的版本目录。
2. V1 请将目录命名为 `rogue_servitor_enhanced`；V2 请命名为 `rogue_servitor_enhanced_v2`。
3. 将该目录复制到 `Documents/Paradox Interactive/Stellaris/mod/`。
4. 把版本目录下 `launcher/` 内的 `.mod` 文件复制到上一级 `Documents/Paradox Interactive/Stellaris/mod/`。
5. 在 Paradox Launcher 中启用模组。

目前主要本地化语言为简体中文，目标游戏版本为 Stellaris 4.4.*。
