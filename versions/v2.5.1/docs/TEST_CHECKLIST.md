# V2.5.0 正式版游戏内验收清单

## 2.5.0 快速测试

```text
effect add_building = building_rse_maid_base
effect add_building = building_rse_maid_workshop_coordination
effect add_building = building_rse_maid_automation_coordination
research_technology tech_mine_dark_matter
effect set_country_flag = transformation_nanotech
effect set_country_flag = transformation_modularity
effect set_country_flag = transformation_virtuality
```

- 机械女仆生产政策七项文本应依次显示20/0、18/2、15/5、10/10、5/15、2/18、0/20；100岗位、100%效率时与资源栏实收一致。
- 分开测试三条 `transformation_*` 旗标；实际正常游戏只会选择一条。采纳对应纳米、模块化或虚拟化传统后，对应路线产出应翻倍。
- 用 `activate_tradition tr_rse_exclusive_service_finish` 后启动合成时代嬗变局势，正常速度下每月应比原版多5进度；暂停局势时不得继续增加。
- 研究暗物质收集后，开启精炼的机械女仆应新增暗物质与对应矿物消耗；切换停止精炼决议后全部附加路线停止。
- 子个体订制节目中心的领袖经验+10%与领袖维护-10%应有明确文本；三种媒体基地的活體陳设条件效果应随有效劳动力变化。

## 法令文本与服务器升级

- 法令页面应以简体中文显示“随身空间利用”“陈设增长再编法案”“招募活體陳設领袖”及各自说明，不得显示原始键值。
- 执行主服务器升级后，“服务器升级忙碌中”应显示并实际提供有机人口培育+30、活體陳設效率-50%、机械人口岗位效率-30%，持续5年。

## 榨汁中与监控模块

1. 准备两颗都有活體陳設的殖民地，增长政策切换到“榨干他们”。
2. 只在其中一颗启用监控模块并跨月。
3. 未监控星球的人口应转为独立“榨汁中”岗位，资源、稳定度、岗位效率、特化与支援岗位全部停止；人口维护费不变。
4. 监控星球应继续使用正常活體陳設岗位并恢复全部效果，每月扣 10 能量。
5. 帝国政策不可被强制切回维持计划。关闭监控或切换政策后，两个岗位应自动互换且没有被忽视的活體陳設。

## 居家服务与活动记录者回归

- 行星岗位页面应新增“侍奉者”阶层，位置在“活體陳設”之下、“复合子个体”之上，且只列出居家服务、活动记录者、处理专员与材料合成者；其他岗位必须留在原阶层。
- “侍奉者”阶层标题左侧应显示自定义紫色图标，不应为空白、出现缺失纹理或显示其他阶层图标。
- 在100%岗位效率时，居家服务每100在岗提供反常度-20、机械组装+0.2、有机培育+0.2、防御部队1；个体需求模型使两种组装增加至0.3。
- 活动记录者每100在岗应在岗位面板直接显示社会学9，并实际增加帝国社会学研究收入；其他研究岗位产出+4%、人口帝国规模-2%。
- 永久活动记录把社会学基础产出增加4.5并额外提供人口帝国规模-1%，不提高研究岗位加成。
- 提高机械人口／活动记录者岗位效率后，其社会学和行星修正仍会随有效劳动力变化；这是预期行为。
- 单独增加活动记录者数量时，核对每名活动记录者自身社会学的倍率：其提供的 `planet_researchers` 加成不得出现在自身资源倍率中；总产出应为线性而非平方增长。
- 改变复合子个体岗位效率后，四个侍奉者岗位的有效劳动力不得变化；改变机械人口岗位效率时则应正常变化。
- 连续增加四种侍奉者岗位数量，确认其自身效果不会反向进入侍奉者阶层效率，曲线应保持线性。
- 四个侍奉者岗位应优先于普通经济子个体岗位自动填入；其基础权重为50。机械女仆、居家女仆与参观规划者仍为20，战士／突触／繁殖子个体不应被强行排挤。
- 清空岗位、使星球被占领或转移所有权后，岗位本体效果应随岗位重算消失。
- 活體陳設基础凝聚力为 1；个人记录后为 2；服务专精后为 3。
- 华丽别墅、女仆天堂、城市穹顶和行星穹顶各使所在星球岗位凝聚力产出 +100%。

## 建筑与升级

可在选中星球后快速加入合并建筑：

```text
effect add_building = building_rse_alley_clothing_workshop
```

- 后巷服装订制厂提供 150 处理专员和 150 材料合成者。
- 后巷服装订制厂应使当地活體陳设食物维护费+25%。
- 女仆基地可升级为女仆中心；两级均可招募战斗女仆并保留200／500机械女仆岗位，不应删减猎寻者或额外新增居家服务岗位。
- 女仆基地／中心所在星球的居家服务应继承猎寻者／执法者的资源产出与维护费修正；拆除后继承立刻消失。
- 女仆工坊协调中心不改变工匠或机械女仆岗位数量；所在星球的机械女仆应继承工匠资源产出与维护费修正，其他星球不继承。
- 工坊建成后，全国机械女仆仍应产生每100岗位20贸易额。
- 居家服务组装与有机培育随岗位效率改变；普通星球分别不超过10，理想乐园分别不超过20，清空岗位后下一月归零。
- 三种模拟器在物种模板中不显示数值效果行，但实际月度缩放效果仍正常。
- 女仆自动化协调中心只能建一座；固定-40%自动化劳动力、-20%自动化岗位维护，100名满效率协调员抵回+50%。
- 建造列表、已建建筑数据库与文本中均不应再出现神秘小馆或有机材料固化厂。
- 合并建筑的建造成本应为2800矿物、1000食物、500合金；维护费为25能量、10食物、10矿物。
- 若旧存档中的两座旧建筑尚未在2.0.3完成迁移，它们会消失；选中原星球后使用上方指令补回合并建筑。
- 华丽别墅 → 女仆天堂正常升级。
- 研究 `tech_fe_dome_1` 后可升级城市穹顶；研究 `tech_fe_dome_2` 后可升级行星穹顶。
- 城市穹顶：5000 住房、5000 活體陳設、1000 居家女仆。
- 行星穹顶：10000 住房、10000 活體陳設、2000 居家女仆、人口维护费 -5%。

## 陈设活动范围

- 城市：每 100 活體陳設提供复合子个体 +1.2%、劳工与简单子个体 +0.2%。
- 不限：每 100 活體陳設提供复合子个体 +0.7%、劳工与简单子个体 +0.7%。
- 乡村：每 100 活體陳設提供复合子个体 +0.2%、劳工与简单子个体 +1.2%，并保留轰炸减伤。
- 三项政策下均不得显示或实际提供“机械人口岗位效率”。
- 选择“不限”时只应出现一条来自活體陳設的劳工与简单子个体效率，752名活體陳設应显示复合子个体与劳工／简单子个体各+526.4%；启用“劳动模拟”也不得出现第二条+752%。
- 在机械星球或理想乐园启用“生产活动参与”，三种生产枢纽区划应各提供100活體陳設与100参观规划者岗位；增减区划后跨月更新。

## 科技、生产政策与物种权利

- 科技顺序应为“个人记录 → 服务专精 → 机械女仆”；子个体轮调与有机体思维解构也要求服务专精。
- 机械女仆生产共有0%、10%、25%、50%、75%、90%、100%七档；10%档每100岗位为1350消费品与150合金，90%档为150消费品与1350合金。
- 专属侍奉路线下，非创始有机物种可以选择原版奴隶公民权；带“受侍奉创始种族”特质的物种仍不可奴役。
- 普遍庇护路线选项只显示一条“正常有机帝国评价+50”摘要，不展开全部帝国名称；实际关系修正仍逐国生效。

## 机械女仆有机增长移除

- 研究“女仆侍奉”与“欲望分析”后，机械女仆岗位不得显示或产生有机人口培育／增长。
- 女仆纪念碑只保留活體陳設+5%与机械女仆+20%岗位效率，不再按机械女仆数量提供有机增长。
- 从2.0.8旧存档更新时等待一次月度结算，原有 `rse_maid_monument_scaled` 增长修正应消失且不再恢复。

## 领袖与事件

快速事件：

```text
event rse_v2.20
event rse_proto.200
```

- 重新伟大的种族立即给一名创始活體陳設科学家，并解锁后续三类领袖招募。
- 包围事件只从现有机械科学家抽取候选；第二阶段只给所选领袖一种最终特质并移除待定特质。
- 事件完成后，5 级以上机械领袖升级时可选择花嫁／公共暴露／随身罐子，三者互斥。
- 扩展升级选项只加给机械领袖；活體陳設领袖不应取得。
- 随身罐子只给其他机械领袖经验 +10%、维护费 -10%；持有者本人和有机领袖不受网络加成。
- 花嫁若因特殊效果死亡，替代者保留姓名、外观、等级、类别和已有特质，不恢复内阁席位或指派。
- 白色领袖开始后自动持续 300 天，不能暂停或取消；完成后领袖返回并给星球 10 年常识修正。

## 既有核心回归

- 一般公民权有机物种不能产生普通领袖；创始有机物种仍为生物纪念品／活體陳設。
- 停止有机增长不影响原版停止子个体生产。
- 战斗女仆伤害 12.5、生命 15、无士气、附带伤害 50%，招募花费250消费品。
- 理想乐园清除障碍、保留特殊地块、区划上限 +50%，使用都市背景。
- 研究原版火山环境改造科技后，火山星球可直接改造为理想乐园；未研究时该链接不可用。
- 理想乐园的樞纽区划可选择“食物聚焦”，并产生农业子个体及农业建筑槽位；普通机械星球不会因为本模组额外取得该选项。
- 保留天然气特殊地貌的理想乐园在研究异星天然气开采科技后，可选择原版樞纽版“异星天然气捕获”；没有对应地貌时仍不可选择。
- 机械女仆工业、七档生产政策、精炼开关、活体金属及再编法案按当前数值回归。
- 检查 `error.log` 与 `game.log`：除必要的原版同键覆写提示外，不应出现本模组未知键、错误 scope、缺失本地化或重复事件 ID。

## 明确不测试

污染数据库／监管地附庸、附庸契约与地产、女仆工坊工匠转职、自动泰坦不属于正式 2.0。
